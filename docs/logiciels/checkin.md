## {nump}`section`. Troisième méthode d'authentification

La troisième méthode d'authentification est une méthode de secours en cas de
perte de votre smartphone.

1.  Connectez-vous à [https://mysignins.microsoft.com/security-info/](https://mysignins.microsoft.com/security-info/). Pensez à accepter de rester connecté pour éviter de devoir rentrer vos
    informations à chaque connexion.
    ```{figure} images/connexion.png
    :width: 40%
    ```
2.  Ajoutez une méthode de connexion qui n'est pas en lien avec votre smartphone,
    par exemple une adresse mail privée.

En cas de problème de connexion [https://eduetatfr.sharepoint.com/sites/FRITIC-M365usages/SitePages/FAQ-MFA-SSPR.aspx/](https://eduetatfr.sharepoint.com/sites/FRITIC-M365usages/SitePages/FAQ-MFA-SSPR.aspx/)

## {nump}`section`. Installation de la suite office

Il est obligatoire d'installer la suite office (Outlook, Word, PowerPoint,
Excel, OneNote, ...) en local sur votre machine, **même si vous avez déjà les
applications de votre compte privé**.

1.  Connectez-vous à [https://m365.cloud.microsoft/apps](https://m365.cloud.microsoft/apps/)
2.  Cliquez sur "Installez apps" en haut à droite et sélectionnez
    "Microsoft 365 apps".
3.  Cliquez sur "Installer Office". Vérifiez que la langue est correcte.
4.  Patientez.
    ```{figure} images/patienter.png
    :width: 40%
    ```
5.  Ouvrez Outlook et envoyez un mail à votre professeur.e de classe.

```{poll} ce974b7c-10e5-4fab-8662-1cdde5471daf
:number: none
Avez-vous installé les applications office?

- oui (passez à la suite)
- non (informez l'enseignant.e)
```

## {nump}`section`. Installation de Safe Exam Browser

1.  Allez sur [https://safeexambrowser.org/download_en.html](https://safeexambrowser.org/download_en.html)
2.  Choisissez la version qui correspond à votre ordinateur (Windows ou MacOS).
3.  Sauvegardez le fichier.
4.  Cliquez sur l'installateur.

Si vous êtes sur MacOS, vous pouvez aussi installer l'[application examen.net](https://apps.apple.com/fr/app/exam-net/id1496582158?platform=mac)

## {nump}`section`. Utilisation des imprimantes/photocopieuses de l'école

Vous avez reçu un badge qui vous permet d'imprimer sur les imprimantes de
l'école, pour cela il faut associer votre badge et votre compte.

1.  Trouvez votre code NIP à 6 chiffres avec une des 2 méthodes ci-dessous.

    -   Le code NIP a été envoyé par mail, retrouvez-le.
    -   Connectez-vous sur [Uniflow Online](https://eduetatfr.eu.uniflowonline.com/Login?ReturnUrl=%2F&#Dashboard/).
        Votre code NIP s'affiche en cliquant sur les `...` (voir flèche rouge).
        ```{figure} images/nip.png
        :width: 90%
        ```
2.  Activez votre bagde sur une photocopieuse et entrez votre PIN à 6 chiffres (à
    faire une seule fois)
3.  Pour savoir comment imprimer, consultez [https://eduetatfr.sharepoint.com/sites/FRITIC-M365usages/SitePages/Uniflow-Online.aspx](https://eduetatfr.sharepoint.com/sites/FRITIC-M365usages/SitePages/Uniflow-Online.aspx).
