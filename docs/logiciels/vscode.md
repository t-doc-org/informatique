# Visual Studio Code

Visual Studio Code est un éditeur de code développé par Microsoft disponible sur
Windows, macOS et Linux.

## Installation

1.  Téléchargez la version de [Visual Studio Code](https://code.visualstudio.com/download)
    qui correspond à votre ordinateur (Windows, Mac ou Linux).
2.  Lancez l'installation en double-cliquant sur le fichier téléchargé.
3.  Démarrez l'application Visual Studio Code.
4.  Activez l'enregistrement automatique en cliquant ***File -> Auto Save***.

## Installation de l'extension French Language Pack

Pour une version française de VSCode, installez l'extension suivante:

1. Dans VSCode, cliquez dans le menu à gauche sur ***Extensions***.
2. Recherchez l'extension **French Language pack for Visual Studio Code**.
3. Cliquez sur ***Installer***.
4. Cliquez sur ***Change Language and Restart***.

## Version Web

Si vous ne pouvez pas installer l'application Visual Studio Code, vous pouvez
utiliser la version Web: [vscode.dev](https://vscode.dev).

Activez l'enregistrement automatique en cliquant ***File -> Auto Save***.

Pour une version française, installez l'extension suivante:

1. Cliquez dans le menu à gauche sur ***Extensions***.
2. Recherchez l'extension **French Language pack for Visual Studio Code**.
3. Cliquez sur ***Set Display Language*** et ***Reload***.
